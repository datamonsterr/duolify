Welcome & chat onboarding

Setup is a friendly chat, not a form. The assistant asks one question at a time with quick replies, follows up only when an answer is vague, and shows a live summary the learner confirms or edits. Every question can be skipped; “Prefer a form?” opens the same fields as a form. The setup chat is free. Desktop and mobile have the same steps and actions — desktop shows the summary panel side by side, mobile opens it as a sheet.
