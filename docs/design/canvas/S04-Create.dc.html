S04–S07 · E2 Course creation

Create a course — clarify, confirm, preview, shape the outline

Four steps: Brief (a clarifying chat fills a course brief), Confirm brief (nothing is charged until the learner confirms), Preview (sample slides + sample outline, 25 credits), Outline (reorder units and lessons by drag or move buttons, rename, remove, or ask the chat for changes), then Create outline (up to 55 credits). Proposed: the clarifying chat is free; chat edits to the sample outline cost about 5 credits each and can use daily free credits — both need E12 sign-off. Desktop and mobile offer the same steps and actions.
