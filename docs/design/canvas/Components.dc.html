C17 · Responsive shells (desktop first, same functions on mobile)

App shell
Desktop: 224px sidebar (Learn, Courses, Marketplace, Friends, Leagues, Quick notes, Bookmarks · Credits, Profile) + 300px progress rail. Mobile: 5 bottom tabs + header stats; More lists the rest.
Focused shell
Player, test, finish, create course. Desktop: top bar with Exit and progress, panels dock right. Mobile: same top bar; panels become full-height sheets.
List + detail
Friends, notes, tutor threads, settings. Desktop: split view. Mobile: list screen → detail screen with Back. Same actions in both.
Side panel ⇄ sheet
Course brief, tutor, quick note, transcript, outline chat. Desktop: docked panel beside content. Mobile: sheet or step screen. A function never exists on only one platform (moderator console is internal, responsive page only).
