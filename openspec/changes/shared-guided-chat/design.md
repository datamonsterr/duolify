# Component boundaries

Controlled data and callbacks let setup, brief and outline consumers own AI calls, persistence and payment consent. Chat renders streaming text outside live regions; a separate polite log receives completed assistant messages once per stable message ID. Composer remains mounted and retains focus after replies.

Summary lines are labelled editable fields with explicit confirmation and unsaved status. Outline units/lessons have stable IDs; mutations produce immutable snapshots for Undo. Drag and move buttons share reorder logic. Proposal changes have textual type labels and explicit Apply/Discard.

A single content subtree moves between a docked panel and native dialog presentation at 48rem, preserving draft state. Modal opening pauses an optional player host, traps focus and returns it on Escape/close. Closing never resumes playback automatically. Focus falls back to the mobile trigger when a resize removes a desktop target.

The standalone guided-chat.html fixture is a Vite multi-page entry, independent of App.tsx. It demonstrates setup/brief and outline compositions, form fallback, loading/empty/offline/error/long-content states, native radios/toggles and pending confirmation. No fixtures are persisted.
