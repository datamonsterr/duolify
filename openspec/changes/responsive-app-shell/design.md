# Composition and boundaries

Use the existing code-based TanStack Router. One stable content host scrolls at every breakpoint; pathname-keyed in-memory restoration preserves tab position. CSS changes presentation without remounting route or panel children. Navigation uses native links and explicit current-page markers. Headings receive focus without scrolling after route rendering, including asynchronous content. Pending, error and not-found states have safe recovery.

The information architecture is canonical for destinations; Marketplace remains Courses' Discover surface. Never invent streak, balance or XP values. Rail links remain available through routes on mobile; the balance shortcut says unavailable until canonical wallet state exists.

ResponsivePanel is a layout host, not E13-03's shared sheet component. It preserves its child tree across docked/modal/step presentation and supplies modal focus containment/restoration. ListDetailLayout accepts separately routed list/detail content and lets feature owners retain their data above it. Feature tickets own course brief/chat/note editors, saving and AI; no fixture editor is presented as saved production data.

Official references checked: TanStack Router navigation, scroll restoration, not-found and data-loading guides; React useEffect/useSyncExternalStore; MDN dialog. Tokens override canvas literals. Platform safe areas, viewport constraints, grid fractions and 1px hairlines are layout geometry exceptions.
