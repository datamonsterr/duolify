## Decisions
- **Listing table.** `marketplace_listings(course_id PK, owner_id, draft_id, version, title, description, category, language, tags, lesson_count, generated_lessons, search tsvector, published_at, delisted_at)`. Title and description come from the latest passing draft snapshot, never from client input. `search` is built at write time with the `simple` configuration (no stemming: courses are multilingual): title weight A, tags B, description C. GIN index on `search`.
- **Category taxonomy** (fixed): `science`, `tech`, `languages`, `life_skills`, `arts`. Language is a BCP 47 primary tag such as `en`.
- **Visibility.** Listing sets `courses.visibility='public'`; delisting returns it to `link` when a share link is live, else `private`. A delisted listing row is kept (`delisted_at`) and is filtered out of every query.
- **Ranking inputs** live in `marketplace_listing_stats(course_id, enrollments_30d, completion_rate, rating_sum, rating_count, popular_score)`, refreshed by `RefreshStats` (periodic in `Maintain`, and after listing). `rating_sum`/`rating_count` are written by E15-08; they are zero now.
  - `popular`: `popular_score = enrollments_30d * (0.5 + completion_rate)`; `completion_rate` is the mean over copies created in the last 30 days of passed lessons / total lessons. Ties: `published_at DESC`, `course_id DESC`.
  - `rating`: Bayesian average `(C*m + rating_sum) / (C + rating_count)`, `C = MARKETPLACE_RATING_MIN_COUNT` (default 10), `m` = platform mean of all listed ratings or the configured prior (default 3.5) when none exist. Zero ratings gives `m`. Ties: `rating_count DESC`, `published_at DESC`, `course_id DESC`.
  - `new`: `published_at DESC, course_id DESC`.
- **Cursor.** Opaque base64url JSON `{sort, key, at, id}`; keyset comparison on the same tuple used for ordering. A cursor for another sort, malformed, or oversized is `invalid_cursor` (400). Page size default 20, max 50 (config).
- **Search.** `websearch_to_tsquery('simple', q)` (never raises on user input); `q` is trimmed and capped at 100 characters (config). The query text is never logged or sent to analytics; only `query_length`.
- **Redis cache.** Keys `marketplace:v1:page:<sha256 of normalized params+cursor>` with a TTL (default 60 s), and a registry set `marketplace:v1:keys`. Any listing change deletes every registered key and the registry. Reads that fail or miss fall through to Postgres; Redis is optional (nil client = no cache). Signed-in viewers with at least one block bypass the cache so the blocked filter is exact.
- **Eligibility** is evaluated at listing time, and again when the owner relists. Verified email = a row in `auth_identities` (email code) or `auth_provider_identities`; account age = `learners.created_at`; generated Lessons from the passing snapshot.
- **Course page** reuses `BuildPreviewPayload` (E15-02 allowlist): same outline, same 3 sample Slides, enrollment count. Added: category, language, published date, rating average and count, and `viewer` state (enrolled copy id). "Cost" copy says the rest are generated for Credits at the active Pricing config; no price is hard-coded in the client.
- **Enrollment.** `Enroll` is refactored to `enrollCourse(ctx, viewer, courseID, ownerID, source)`; link enrollment and marketplace enrollment share it, so pinning, daily cap and zero-credit reuse are identical.
- **Rate limit.** Reuse the Postgres per-IP limiter (`AllowPreview`) for the public reads with its own key namespace.
- **Release flag.** `MARKETPLACE_ENABLED` (default false) in `Config`; surfaced through `GET /v1/features`. Owner listing routes are also refused (404) while off.
- **Analytics.** Server emitted: `marketplace_browsed(category?, language?, sort, result_count, has_cursor)`, `marketplace_searched(query_length, category?, language?, sort, result_count)`, `course_viewed(course_id, version, surface:'marketplace')`. A search with `q` emits `marketplace_searched` instead of `marketplace_browsed`. Anonymous viewers aggregate under the reserved operations id (as `share_link_opened`). Opt-out is honored by the existing consent gate.
- **Backup.** `marketplace_listings` and `marketplace_listing_stats` are plain Postgres tables in the nightly dump. Redis is not backed up and rebuilds. Account deletion cascades both.
