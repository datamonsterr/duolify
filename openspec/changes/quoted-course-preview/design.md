# E2-01 design

Reuse E2-06 immutable revisions and current profile reads, E12 action quotes/consent and E7-03 ReserveAction/Limits/Claim/Settle. QuoteInput adds only an opaque revision ID to its existing immutable financial snapshot. Preview execution rejects absent/mismatched/superseded/expired confirmation before reservation. New confirmation supersedes previous preview intent; old revisions stay exportable until expiry. No new table, provider credential, price or persistent preview output.

Preview validation runs inside the shared engine cost/deadline loop via a schema callback. The stricter monetization/E7 policy takes precedence over the older base three-attempt example: primary then at most one evaluated fallback, and only when the full remaining fallback envelope fits. Attempts share total deadline and USD cap, including unknown usage holds. Malformed schema, unsafe slides and blank titles/goals are undelivered. API validation independently verifies the returned sample before settlement. Pending-only release reuses the financial finalizer and cannot cancel a competing running executor.

Client keeps E2-06 account-scoped session draft and a component-only preview. Explicit Review cost follows brief confirmation; explicit Confirm & preview accepts the fresh revision-bound quote before invoking paid execution. Back, discard, shop return, offline failure and edited fields preserve authored intent; every regeneration requests new terms. The sandbox denies same-origin, network, forms and navigation privileges; playback uses the existing pause/motion bridge and always exposes narration text. Outline review uses native disclosures; the editor and creation stay E2-07/E2-02.

Existing privacy classifications already cover course_brief_revisions (erased), pricing_quotes and credit_jobs (financial retained with identity severed), and usage/allocation records through the job. Backup fixtures now seed a revision-bound preview quote. General snapshots retain 14 days, financial snapshots 35 days and live financial rows seven years. No brief text enters financial snapshots or analytics. Offline recorded fixtures run through production prompt construction, validation and bounded execution; E10-06 remains the live promotion gate.
