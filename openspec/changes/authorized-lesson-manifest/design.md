# Design
Postgres lesson_manifests references an enrolled course_lesson_stub and an immutable manifest object key. Manifest JSON and HTML are versioned application objects; stable keys include a content version. The API returns a closed DTO with slide IDs, duration, asset references, checkpoints, captions and an authenticated document path. Fixture narration is explicitly disabled with readable narration_text; synthesized audio remains E14. Neither assessment content nor answer keys belong to this DTO.

All reads join live courses and course_enrollments, including individual slide reads. Unknown, deleted and other learners' lessons share a 404. Missing or corrupt objects fail closed with a retryable 503. Reads never write progress, XP or completion. Fixture publishing is test-only; new course stubs are not implicitly generated.

The authenticated host fetches HTML and creates srcdoc with a CSP before any untrusted bytes. Only the configured asset origin can load resources/connect; object-src, frame-src, form-action, base-uri and workers are denied. No allow-same-origin, navigation, forms or popup sandbox privileges are granted. Messages require the active contentWindow, opaque origin and an exact bounded schema; checkpoints must occur in the active manifest. An iframe is replaced per slide. Untrusted HTML is never inserted into the host DOM.

Retain E13 tokens and focused desktop/mobile layout, responsive sheets, caption overflow, loading, error/retry/exit, offline explanation, focus and reduced motion. Take lesson test navigates to the existing test destination. No slide-view/completion analytics are emitted by E3-01. Catalogue events carry only opaque IDs and fixed error codes; identity/opt-out use existing wrappers.

Data: metadata exports and cascades with the learner/course; deletion tombstones reapply on restore. Nightly encrypted general Postgres dumps retain 14 days. Versioned manifest/HTML/assets use protected nightly copies/checksum manifests under the existing data-backup policy; fixture restore verifies pinned object bytes without model calls. No device durable content cache is introduced. No AI calls, new model settings, secrets or proto changes.
