# Design
Reuse E2-07 ResolveConfirmed, E2-08 applied revisions, E12 quotes and E7 reservation/settlement. Financial snapshots contain identifiers/hash only. Transactionally enqueue opaque creation IDs; persist the exact content-free request before provider work. River retries recover validated output and settlement without another provider call. A claimed call interrupted before durable output fails closed and releases undelivered Credits, rather than spending twice. Units/stubs/enrollment commit together only after validated settlement. First stub is ready_to_generate, remaining stubs locked. SSE exposes fixed stages and public IDs only. Production model bounds remain pinned to the quote; the evaluated bounded primary/fallback loop takes precedence over the older three-attempt example. New learner tables cascade account erasure and export via the owner; general backups retain 14 days, financial snapshots 35 days. Course soft-delete metadata supports the existing 30-day retention contract; deletion UI remains E2-04. Offline fixtures gate development under ADR 0011; E10-06 gates live promotion.
