# Design

The public read-only demo endpoint serves embedded, Git-versioned authored assets under an immutable version key. It accepts no learner input and has no database, engine or wallet dependency. The protected object-copy fixture stores and restores the exact authored bundle with checksum/version evidence. No personal demo data exists, so account export/deletion policies are unchanged.

Welcome and Create use the same demo viewer. The Create tree stays mounted and inert/hidden during the demo; its brief answers, composer and edited outline remain intact. Opening a demo invalidates any pending paid quote and preview operation, including stale asynchronous responses. Return resumes creation but a new quote and explicit paid-preview consent precede custom generation. No demo course can be enrolled or created.

Slides use the existing E3 sandbox document rendering and playback bridge, strict CSP, reduced-motion handling, transcript and learner-initiated playback. Loading/error states retain Return and Retry. Development serves the example without activating any approved production pricing catalogue; E12-08 remains the launch-policy gate. No effort rewards or subsidies are introduced.
