## Why
Accepted quotes currently record consent without holding funds or operational budgets. E7-03 needs one durable boundary before provider jobs.

## What Changes
- Reserve eligible source buckets and USD capacity atomically with an idempotent job.
- Pin original terms and report bounded per-attempt usage across API and engine.
- Settle delivered content/audio independently, retain failed-attempt provider cost, release unused funds, and expire released old daily funds.
- Add accessible reservation/recovery controls to the shared quote panel.

## Impact
Credits, pricing policy, API, private protobuf contract, engine, client, financial backup and privacy policy. No provider or live sales activation.
