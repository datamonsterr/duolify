# Transcription spike (voice input, task 1.3)

Throwaway comparison of OpenRouter speech-to-text models for the `voice-input` capability of
`openspec/changes/immersive-mobile-lesson-player`. It does not touch `evals/pinned-datasets.toml`,
`evals/promotion/` or `evals/datasets/`, and nothing here is wired into `mise run engine:eval`.
Results and tables: [`RESULTS.md`](RESULTS.md). Decision record: [ADR 0021](../../../docs/adr/0021-voice-input-data-handling.md).
Platform capture findings: [`docs/design/voice-input-platforms.md`](../../../docs/design/voice-input-platforms.md).

## Files

| File | What |
|---|---|
| `manifest.json` | the 16 clips: id, category, source, item, licence, language, reference text, duration |
| `prepare.py` | rebuilds the audio (downloads from Hugging Face, generates noise and silence, optional ElevenLabs, converts to WebM/Opus and MP4/AAC) |
| `run.py` | `run` (evaluate), `policy` (data-collection and ZDR routability), `report` (markdown tables) |
| `results.json`, `policy.json` | raw rows from the 2026-11-22 run (transcripts and costs, no audio, no key) |

## Clip set and licences

No audio is committed. The two generated clips (silence, noise-only) are rebuilt by `prepare.py`; the rest is fetched.

| Category | Clips | Source | Licence |
|---|---|---|---|
| clean English read speech | `en-clean-1..3` | `openslr/librispeech_asr` test.clean (LibriSpeech) | CC-BY-4.0 |
| accented English | `en-accent-1..2` (Scottish, Hong Kong) | `MushanW/GLOBE_V2` test (Common Voice derived) | CC0-1.0 |
| background noise | `en-noisy-1..2` | `en-clean-2` and `-3` mixed with pink noise (SNR 11.8 dB) and brown noise (6.9 dB) | derived, CC-BY-4.0 |
| silence and noise only | `silence-1`, `noise-only-1` | ffmpeg `anullsrc`, `anoisesrc` | generated |
| technical vocabulary | `tech-1..4` | four sentences with `const`, `closure`, `roadmap`, `OKR`, synthesised with the project ElevenLabs voice (346 characters) | generated by us; synthetic speech is cleaner than a human mic, so it flatters every model |
| Vietnamese | `vi-1..3` | `google/fleurs` vi_vn test | CC-BY-4.0 |

Licence checked on each dataset card through the Hugging Face API on 2026-11-22. CC-BY and CC0 permit redistribution
with attribution, but the audio is not copied into the repo; keep the attribution if any clip is ever published.

## Run it

```sh
cd evals/spikes/transcription
uv run --with pyarrow python prepare.py --out audio --tts     # ~1.2 GB download; --tts spends 346 ElevenLabs characters
OPENROUTER_API_KEY=... python run.py run --audio audio --models openai/whisper-large-v3-turbo,qwen/qwen3-asr-0.6b --out results.json --budget 0.45
python run.py policy --audio audio --models mistralai/voxtral-mini-transcribe-3-0 --out policy.json
python run.py report --results results.json
```

The key comes from the environment only and is never printed or stored. `run` skips rows already in the output file and stops
at `--budget`. `prepare.py` was assembled from the scratch scripts that produced the committed results and was not re-run end
to end after consolidation; the clip selection logic is deterministic and the ids and references in `manifest.json` are
the ones that were evaluated.

## How to turn this into the Golden set (task 6.7)

The Golden set lives on Hugging Face, so this folder only proves the method. Port the manifest rows into the dataset with
audio, keep `norm()` and `wer()` from `run.py` as the scoring rules, and add 5 to 10 clips per category (the 16 clips
here are too few to rank models whose WER differs by less than 2 points).
